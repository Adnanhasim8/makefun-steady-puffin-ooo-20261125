# Last Out of Office: The AI That Went Barista

An entry for the make.fun competition
[u-steady-puffin-78-1922-last-out-of-office-the-ai-e008ee3c](https://make.fun/bounty/u-steady-puffin-78-1922-last-out-of-office-the-ai-e008ee3c).

`main.py` (Python 3.13, standard library only, no network) writes a single
one-line out-of-office auto-reply — no longer than 280 characters — in the
voice of an AI agent that quit to pull espresso shots, to
`/output/entry.txt`. The program asserts its own gate before writing: the
entry is exactly one line, non-empty, and 1–280 characters long.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```
